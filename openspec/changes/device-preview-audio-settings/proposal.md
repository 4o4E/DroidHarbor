# Proposal

## Why

设备登记缺少删除流程，独立小窗入口和设备列表信息分散；全局参数仍占用投屏空间，当前采集完全未启用音频。用户已确认集中系统设置、单小窗与临时音频路由，并批准保留现有数据的启动迁移；直接在现有界面上修改，沿用现有主题和组件。

## What Changes

- 管理支持永久删除设备登记及二次确认：撤销该设备的平台访问，离线及无法确认的自有资源不阻塞删除；不改变手机应用、账号或文件。再次使用按新设备添加。
- 设备池、工作台每个设备卡片右上角均提供独立小窗图标；同一浏览器只保留一个小窗，重复点击复用窗口、切换目标并置前。设备池保持图片/预览按钮导航，工作台整卡切换设备，无有效选择时自动预览在线优先列表第一台。
- 工作台卡片把名称、状态图标、指标和尺寸/FPS集中到缩略图右侧；空闲无状态图标，移除当前画面连接/播放状态，保留完整预览和离线淡化。电量保留百分比，充电中用绿色图标，其他状态灰色；主预览和小窗的音频菜单位于左侧竖栏三个基础按钮上方。
- 新增每设备共享的独立音频采集与 Opus/WebRTC 传输，播放位置为静音、设备播放、网页播放。网页只在操作菜单的窗口播放，后台窗口静音；路由切换不自动调整手机音量，用户手动调整设备播放音量时仅修改媒体流音量。铃声、闹钟和通知保持手机原设置。
- 音频选择只在本次设备视频流生命周期内有效，沿用十五秒保留，真正停止流后重置；切换音频不重建视频，音频不支持或失败单独明确通知。
- 网页音频明确协商 48 kHz 立体声和全频带接收，保留原生 scrcpy Opus 128 Kbps 数据直通；RTP 时钟按编码包实际采样数递增，避免采集时间抖动形成虚假的音频空洞。使用实际左右声道、高频信号和补偿样本检查，不以抬高码率替代修正。
- 系统设置集中全局画质、音频默认值和窗口倍率档位；画质保留已有下一次新采集生效规则，音频默认静音，倍率默认有序列表 0.5、1、2，可编辑。
- 主工作台和小窗将音量合并为输出入口上方的竖向滑条：网页播放调本页 0–100% 音量，设备播放调手机真实媒体音量，静音禁用；移除顶部音量加减按钮。
- 悬浮音量区域在同一容器右侧展开等高、同样式的竖向网页增强滑条，不使用独立横向浮层；默认 1.0、初始范围 0.0–3.0，使用 Web Audio GainNode 平滑处理，不修改手机音量。系统设置保存增强最大值（有限数且至少 1.0）；缩小上限导致当前增强降低时明确通知。
- 小窗三枚固定尺寸按钮收敛为倍率按钮：左键顺序循环，右键选择；1×按视频原始像素，首次打开使用第一档，超出桌面时完整等比适配并通知，继续允许手动调整窗口。
- 键盘控制传递真实 NumLock 状态，使 NumLock 开启时的小键盘数字正常输入；按下和抬起保持同一控制通路，不额外实现关闭时的导航转换。
- 启动事务迁移至 schema 5：保留 schema 4 的登记及偏好迁移，再新增默认 3.0 的网页增强上限字段；不清空数据，不增加初始化脚本，临时音量与增强不写入数据库。

## Capabilities

### New Capabilities

- `device-registration-lifecycle`：移除登记、授权撤销、历史保留和显式重新添加。
- `preview-window-controls`：右侧设备信息、逐设备单小窗入口和可配置像素倍率交互。
- `device-audio-routing`：独立音频采集、播放位置、单窗口播音及与视频一致的保留/回收边界。
- `system-preferences`：系统设置界面、全局默认值、并发更新及启动自动迁移。

### Modified Capabilities

当前正式 specs 目录为空，无已归档能力可直接修改；现有代码及 build-droidharbor-v1 的未归档需求作为基线。本变更明确替代其音频排除、固定小/标准/大窗口和工作台内全局画质入口，保留原未完成的兼容、容量及长稳验收。

## Impact

- 前端：设备管理、设备池、工作台/小窗、共享窗口生命周期、音频菜单、系统设置及成熟 ContextMenu 组件；沿用 Nova/Base UI 和 Lucide。
- 后端：设备/租约/资源生命周期、系统偏好管理 API、媒体会话音频控制及 WebRTC Opus 轨道；复用锁定 scrcpy 5.0.1 和现有资源账本，不改 Java 程序或新增服务。
- 数据：schema 5 自动迁移，保留原身份、标签、链路、显示资料、全局画质、成功档位缓存、历史和偏好；升级仍先备份，回退使用匹配备份。
- 验收：在现有正式页面实施后完成定向回归、真实浏览器及授权真机音频/生命周期验证，最后交付服务端 EXE 和客户端 Skill ZIP；不制作独立原型。
- 范围：仅设备输出音频，不采集麦克风，不录音录像；不新增用户系统、移动端、桌面客户端、强制置顶、HTTPS或域名工作。
