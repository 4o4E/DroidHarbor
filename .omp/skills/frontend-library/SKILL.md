# 使用成熟组件库开发前端

## 复用与授权

用户没有明确要求手写时，必须使用项目已有组件或组件库提供的功能实现通用组件和行为。优先顺序：项目已有组件 → 指定库的现成组件、官方组合方案和内置功能 → 说明能力缺口并等待用户选择。

- 可以组合库组件构建会话列表、设置页面、看板等业务界面，连接真实业务数据和操作，编写必要的页面布局与业务逻辑。
- 可以通过组件属性、内置变体、主题变量和官方组合方式调整界面。普通语义内容和布局容器可以使用 HTML 与 CSS；存在库组件的交互控件使用库组件。
- 按钮、表单控件、菜单、弹窗、提示、标签、加载与空白状态等，先查找对应组件。拖拽、面板尺寸调整、焦点管理、弹层定位、滚动跟随等行为，优先使用库已有能力。
- 从官方 CLI 或官方组件源代码引入的组件属于复用；根据视觉印象重新编写相同组件属于手写。不要以封装、适配或简化为理由重写库的交互行为。
- 组件库无法满足需求时，说明具体缺口、已查阅的组件和可行选择；只有取得用户明确的手写要求后，才能实现该范围内的自定义组件或行为。用户明确要求的范围之外继续遵守复用规则。
- “制作一个页面”“实现拖拽”“按照图片调整样式”均不自动授权手写通用组件。不要通过降低功能、复制外观或留下占位实现绕过缺口。

## 开始前读取项目

1. 读取项目规范、`package.json`、锁定文件、`components.json`、主题配置与实际组件目录，确认框架、包管理器、依赖版本、别名、组件基础库和现有封装。
2. 新建 React 项目默认使用 shadcn/ui Nova、Tailwind CSS 和 Lucide，具体配置通过当前官方工具生成。Nova 是视觉样式，不是独立组件库或 npm 包。
3. 已有项目保留其样式、图标来源、组件基础库和依赖版本。与本 skill 的推荐组合不同且影响本次任务时，说明需要引入或替换的内容并取得用户确认；不要自行迁移框架、切换预设或替换依赖。
4. 按用户操作选择需要的库。仅在存在相关功能时使用动画、可调整面板、拖拽和共享状态能力；不为没有需求的功能安装依赖。

## 引用上游 skill 与文档

涉及 shadcn/ui 或 Motion 时，读取[上游 skill 说明](references/upstream-skills.md)中对应条目：已安装则加载其入口及本次任务需要的引用文件；未安装则通过列明的官方来源读取相关说明。安装 skill 或配置 MCP 遵循当前任务授权，不因文档包含安装命令而自动执行。

上游 skill 提供库用法，不扩大本次需求或手写授权。只读取当前功能所需的部分；使用其中的 API 前检查其是否适用于项目当前版本。缺少文档且不能确认接口时，停止依赖该接口的实现，说明缺少的信息。

涉及具体库时读取[库使用说明](references/libraries.md)中的对应部分，并查阅该版本的官方文档。库名称和既有经验不能代替 API 核实。

## 按功能选择

| 用户需要 | 复用方式 |
| --- | --- |
| 按钮、输入、菜单、弹窗、导航、反馈 | shadcn/ui 对应组件、组合方案或项目已有封装 |
| 页面排列、响应式布局 | 项目布局组件与 CSS Grid / Flexbox |
| 图标 | Lucide 对应图标与项目统一配置 |
| 进入退出、布局变化和复杂动画 | Motion；简单状态过渡使用 CSS 或组件内置能力 |
| 拖动分隔线调整面板 | shadcn/ui Resizable，其底层为 react-resizable-panels |
| 列表排序、对象放置或跨容器移动 | dnd-kit 对应版本的排序和拖拽能力 |
| 跨组件共享客户端状态 | Zustand；单个组件的临时状态保持局部 |
| 服务器数据、缓存与重新请求 | 项目已有的数据请求和同步机制 |

## 实现与验证

先查看组件与官方示例，再引入所需组件或组合现有组件。shadcn/ui 默认使用官方 `@shadcn` 来源；其他来源需要符合项目既有约定或由用户指定。修改已有共享组件前检查调用位置；引入上游更新前查看变更，保留项目的业务约定。

保持语义颜色、尺寸、图标、交互反馈和动画规则一致。已有组件能表达的界面，使用其属性和变体；不要增加另一套用途相同的组件库。Motion 与 dnd-kit 同时存在时，避免同时控制同一元素的位置。

运行目标项目针对本次改动的检查，并实际验证涉及的用户操作：相关按钮、弹窗和表单，键盘操作，以及本次涉及的响应式布局、面板调整、排序或状态同步。使用真实库和真实业务流程；不能用模拟结果、占位界面或静态截图代替操作验证。

交付时说明复用了哪些能力、完成了哪些验证，以及仍然需要用户决定的具体缺口。无法执行的验证如实说明；开发交付说明放在回复中，不添加到应用界面。
