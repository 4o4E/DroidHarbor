# Spec Delta

## Purpose

为网页管理员、AI 调用方及其独立任务建立清晰的身份和权限合同，让共享调用账号下的任务仍需各自授权才能访问已认领手机，并使凭证撤销真实作用于已建立连接，避免秘密从日志、网页或状态事件泄露。

## ADDED Requirements

### Requirement: 管理员令牌登录
平台 SHALL 支持管理员使用首次启动自动生成的访问令牌建立网页管理会话，并提供退出及令牌轮换方式；不要求账号密码、公共注册或外部 SSO。首次初始化通过控制台和本机初始化日志一次性交付 token，后续启动复用已有摘要且不重复输出。令牌 MUST NOT 写入静态前端、URL 或普通请求日志；初始化日志按登录凭证保护。

#### Scenario: 有效令牌登录
- **WHEN** 管理员通过同源管理入口提交有效管理令牌
- **THEN** 获得网页管理会话，可以管理设备与调用凭证，不需要另建密码账号

#### Scenario: 退出或令牌轮换
- **WHEN** 管理员退出当前会话或在服务器轮换管理令牌
- **THEN** 对应会话或所有旧令牌版本会话失效，既有人工控制连接不再接受未授权输入

### Requirement: 调用凭证可创建与撤销
管理员 SHALL 能创建命名 AI 调用凭证并撤销；秘密只在创建时交付，后续列表不回显。撤销 MUST 禁止新认领并使关联任务的既有访问失效，进入平台资源回收。

#### Scenario: 撤销仍在使用的调用凭证
- **WHEN** 管理员撤销一个存在活跃任务的调用凭证
- **THEN** 新认领被拒绝，关联租约和旧连接失效，不等到调用方主动断开才执行撤销

### Requirement: 同调用账号下的任务隔离
认领后的续租、连接及任务操作 SHALL 需要对应任务的独立凭证；知道共享调用凭证、taskId、leaseId 或幂等键不足以取得另一任务授权。平台 MUST NOT 提供仅凭共享调用凭证找回其他任务秘密的能力。

#### Scenario: 任务 B 冒用任务 A 标识
- **WHEN** 任务 B 使用自己的任务凭证并把请求中的 leaseId 改为 A 的租约
- **THEN** 请求被拒绝，A 的状态、期限和连接不受影响

#### Scenario: 共享调用凭证试图取回已有任务
- **WHEN** 调用方携共享 API 凭证和已知 taskId，但没有原任务秘密，请求恢复或替换该任务授权
- **THEN** 平台拒绝授权恢复，不回显原秘密或签发可控制原租约的新凭证

### Requirement: 所有设备入口持续鉴权
平台 SHALL 对管理 API、租约通道、媒体、人工输入、文件/截图及状态事件执行身份和授权检查；MUST NOT 因入口位于内网/VPN 就省略认证。会话过期或撤销后已建立通道也必须失效。

#### Scenario: 未登录直接访问媒体或文件
- **WHEN** 客户端绕过页面直接请求设备视频、截图或上传入口
- **THEN** 未授权请求被拒绝，不因知道 deviceId 就取得设备内容或操作权

#### Scenario: 会话失效但控制连接仍在
- **WHEN** 人工会话已失效而浏览器仍持有旧控制连接
- **THEN** 后续输入被拒绝，不能仅凭连接仍存在继续控制

### Requirement: 授权范围内的信息可见性
平台 SHALL 仅向调用方提供选机和本任务所需的信息；管理员有完整管理视图。首次管理员初始化日志仅供本机部署者取得登录 token；其余凭证、真实设备管理地址和其他任务私有身份 MUST NOT 通过列表、错误、运行日志或事件暴露。

#### Scenario: 调用方订阅状态
- **WHEN** 普通调用方查询设备摘要或订阅任务事件
- **THEN** 可获知允许的设备可用信息和本任务状态，但不能取得其他任务秘密、管理端口或完整私有记录

#### Scenario: 认证失败被记录
- **WHEN** 请求携带错误或过期秘密被记录到运行日志
- **THEN** 日志保留错误类别与关联请求信息，不保存秘密正文或包含秘密的完整请求体

### Requirement: 明确外部隔离责任
平台产品说明 MUST 明确任务本地端口、进程和凭证不能替代 OS 权限隔离；服务端保证租约入口授权，不保证拥有宿主或手机管理权限的外部程序无法直接操作设备。

#### Scenario: 同系统权限的恶意任务
- **WHEN** 部署人员为多个互不信任任务配置同一 OS 用户和可互读的工作目录
- **THEN** 产品说明要求通过独立用户/容器等运行环境隔离，不宣称 loopback 或独立端口已经阻止凭证窃取
