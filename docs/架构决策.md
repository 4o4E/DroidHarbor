# 架构决策

以下均为用户已确认的现行选择，不记录实施流水。实现结构见[架构设计](架构设计.md)，逐场景约束见[首版合同](../openspec/changes/build-droidharbor-v1/design.md)和[媒体/偏好增量合同](../openspec/changes/device-preview-audio-settings/design.md)；架构或 schema 变化须重新确认，不另建重复 ADR 台账。

| 决策 | 选择 | 原因与代价 |
| --- | --- | --- |
| D1 服务与媒体技术 | Go 服务、Go CLI、Pion WebRTC；手机编码、服务端转发、浏览器解码 | 统一可执行程序分发并复用成熟协议生态；不以语言选择承诺性能提升 |
| D2 AI 操作入口 | Skill + 任务级 CLI + 原生 ADB，经任务认证的二进制通道接入租约网关 | 复用原生工具且统一撤销；不建设第二套 HTTP 点击协议。任务端口/进程不是系统沙箱 |
| D3 回收与重启 | 先撤销访问，再清理平台资源；失败隔离，重启不恢复旧租约 | 保留应用、账号和后台状态；不保证已送达动作或后台副作用终止 |
| D4 部署与网络 | 单宿主 Windows 原生 / Linux 平台与 ADB 双容器，内网/VPN、桌面 Chrome/Edge | 平台可独立更新，不引入集群；应用提供 HTTP/WS，不承担 TLS/域名，明文仅用于可信网络 |
| D5 存储 | SQLite，启动自动事务迁移；当前 schema 5 | 小规模元数据及原子认领不依赖外部数据库；不存媒体，不让多实例共享数据库承担集群协调，回退须匹配备份 |
| D6 租期 | 初次/每次显式续租均从服务端当前时刻起 15 分钟，无累计上限 | 调用方主动表达占用，异常退出最终回收；不由 CLI/流量自动续租，过期不复活 |
| D7 功能边界 | 工作台提供手机剪贴板、文件浏览/上传及当前 Android 用户应用管理；AI 仍走原生 ADB | 共享存储可传输，已有 ADB root 仅扩大可浏览目录；不做应用仓库、群控、录屏、MCP、完整 RBAC。Appium/uiautomator2 仅预留 |
| D8 性能承诺 | 先测新实现，再确认延迟、容量和长稳门槛 | 不把编码目标、带宽算术、编译或短样本当作性能验收 |
| D9 进程与管理身份 | 单 Go 服务统一网页/API/网关/投屏；管理员令牌登录 | 减少部署单元，不建设账号密码/SSO；AI caller/task 授权仍独立 |
| D10 画质 | 全局默认 60 fps/12 Mbps，设备长边策略保留；新建采集生效 | 同机共享流不因保存而打断；仅明确编码配置拒绝允许有限兼容回退，实际成功与目标差异必须通知 |
| D11 切换与预布局 | 持久屏幕/视频几何，每设备独立保留完整视频链 15 秒 | 回切复用连接和解码器；后台仍耗编码/带宽、计入会话容量，不预热未访问设备 |
| D12 在线保活 | 已登记在线设备逻辑唤醒、实体黑屏，空闲使用无音视频控制角色 | 初始化和远程预览不依赖先开网页；不改休眠时限、不解除密码锁，停止后恢复系统正常休眠策略 |
| D13 音频与默认值 | 独立媒体输出路由，默认静音，可设备/网页播放；网页主音量与增强，默认值集中管理 | 切音频不重建视频；临时选择随视频保留、最终释放重置。路由不改系统音量，手动设备音量须核对真实媒体读数 |
| D14 无线发现 | 只用既有 ADB 的 mDNS，保留手动地址 | 不扫描网段端口、不新增发现守护进程；发现不是连接/配对，未广播设备需显式地址 |
| D15 网页与小窗 | 基于现有桌面组件修改，同源 SharedWorker 协调唯一小窗，默认有序倍率 0.5/1/2 | 不独立重做 UI 或增加桌面客户端/强制置顶；关闭创建页不结束小窗，尺寸受浏览器策略约束 |
| D16 交付 | 一个内嵌网页/采集程序的服务端 EXE，一个含 Windows/Linux CLI 的客户端 Skill ZIP；release 根目录仅最新产物 | 用户双击启动，缺配置自动初始化，无示例 env 或 init/启动脚本；发布失败成对恢复，运行数据保留 |

设备标签表示人工配置的环境，不证明账号仍有效；人工介入不自动暂停 AI；完整兼容与容量承诺只由相应合同和验收决定。这些边界不因页面展示、临时连接恢复或新包生成而改变。
