# Spec Delta

## Purpose

将全局画质、媒体音频默认播放位置和小窗倍率集中到现有应用的系统设置页面，通过启动自动迁移持久化，保留在途视频和已有设备资料，避免设置散落在投屏工具栏或依赖初始化脚本。

## ADDED Requirements

### Requirement: 集中系统设置
系统 SHALL 提供全局画质、音频默认值和有序倍率档位，初始音频静音、倍率 0.5、1、2；倍率为有限正数且去重，顺序用于左键循环。修改默认值不改变正在使用的临时音频选择或视频采集。

#### Scenario: 保存设置并重启
- **WHEN** 管理员保存默认值及倍率并重启服务
- **THEN** 保留设置，新小窗使用第一档，新视频使用音频默认值，工作台不再显示全局画质设置

#### Scenario: 并发修改
- **WHEN** 另一个页面已修改同一设置版本
- **THEN** 拒绝过期保存并统一通知重新读取，不覆盖更新

### Requirement: 增量自动迁移
启动 SHALL 从已支持的旧 schema 事务升级至 schema 5，保留设备身份、历史、全局画质、成功档位及已有系统偏好；音频、增强上限及倍率保存不改变画质版本。

#### Scenario: 原数据升级
- **WHEN** 新 EXE 读取 schema 4 数据库
- **THEN** 自动添加默认 3.0 的增强上限，原设备、历史和已有偏好保持，无额外脚本

### Requirement: 全局增强上限
系统设置 SHALL 持久化网页增强最大值，初始 3.0，接受至少 1.0 的有限数；通过偏好 revision 防止过期覆盖。保存后各窗口收到变更，临时增强被新上限限制时明确通知。

#### Scenario: 保存及重启
- **WHEN** 保存新的增强上限并重启
- **THEN** 设置保持，新的增强滑条使用该上限，主音量和当前增强不写入持久化设置
