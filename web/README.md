# DroidHarbor 网页

正式网页直接连接 Go 服务的同源 `/api/v1`，使用真实 Cookie/CSRF 管理会话、SSE 权威快照、WebRTC 视频与 scrcpy 控制；不包含示例设备、演示凭证或离线模拟成功路径。

## 运行

- `npm install`：安装锁定依赖。
- `npm run build`：TypeScript 检查和 Vite 构建；由 Go 服务的 `--web-dir web/dist` 提供产物。管理页与独立小窗按路由拆包。
- `npm run lint`：执行 Oxlint；当前检查通过但存在 30 条 warnings，并非零警告。
- `npm run dev -- --host 127.0.0.1`：仅启动 Vite 开发服务，不自动提供 API 代理。完整联调使用 Go 提供的同源 HTTPS，不降级管理员认证或浏览器安全上下文。

组件使用项目安装的 frontend-library Skill、官方 shadcn Base UI Nova、Tailwind v4 和 Lucide；服务端状态使用 TanStack Query。管理员令牌和 CSRF 只保留在内存；长期凭证不放入 URL、静态包或本地持久存储。

## 页面行为

- 设备卡片整体进入工作台；管理按钮单独打开管理界面，不触发进入工作台。设备、链路、标签、维护状态及调用凭证来自真实 API。
- 工作台左侧保留带预览的设备列表，支持点击及键盘选择。切换设备释放本窗口输入、清除旧画面并保留只读/控制意图，不结束其他观看者或 AI 租约。
- 设备池和左侧列表默认每 5 秒请求共享 JPEG 预览，显示服务端拍摄时间；离开可视区或页面隐藏时停止请求。离线/失败不伪装为新截图，迟到响应按设备与链路代次拒绝。
- 视频必须收到当前会话及采集代次的真实解码帧后才能控制。设备断线后旧会话结束，链路恢复不自动续播，需要显式重试。暂停、显示旋转和镜像仅改变本地显示；旋转手机及设备键走实际控制协议。
- 只读允许观看和原始截图，不允许控制、剪贴板、上传或共享画质修改。普通控制的 `dispatched` 不代表 Android 应用完成；剪贴板等待终态，`acknowledged` 且 `applied:false` 不显示为已应用。
- 共享画质的三个参数独立提交，并展示 requested/effective；revision 冲突必须主动重载，不自动重放旧修改。文件先上传再查询真实推送/安装结果，同名默认不覆盖，覆盖须明确选择；结果未知不伪报成功或自动重试。
- 状态连接断开时显示异常并保留最后快照；恢复后重新订阅及读取权威快照，不依赖断线期间的旧缓存。

## 独立小窗

工作台打开的 popup 只含画面与底部单排按钮，不含设备列表、信息面板或额外工具区域。地址仅携带稳定设备 ID 和只读/控制意图；没有 opener 依赖，主页面关闭或切换不影响它，同设备复用采集，管理员会话注销后停止观看。

小/标准/大按钮根据实际画面比例、浏览器边框及屏幕宽高计算真实窗口尺寸。手动拖动窗口后画面保持等比；浏览器最小尺寸或禁止 `resizeTo` 时明确提示，不锁定外框或反复回弹，不引入桌面客户端。
