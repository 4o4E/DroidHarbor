## 4. 租约、撤销与回收闭环

- [x] 4.1 实现原子认领、同任务/同设备唯一活跃租约和幂等请求结果；并发认领唯一匹配设备及重发丢响应请求，验证只占用一台且参数冲突被拒绝，保留对应回归测试。
- [x] 4.2 实现初次及续租固定 900 秒、单调时钟到期、无累计上限和无隐式续租；用可控时钟验证期限、时间回拨及续租/过期竞态，再实际运行 claim/renew/status 流程。
- [x] 4.3 实现派发授权边界、代次校验、撤销取消及队列丢弃，使阻塞 I/O 不阻碍到期；验证过期后不能派发新数据、清理失败不能重新认领，保留并发状态转移回归测试。
- [x] 4.4 实现平台资源创建前登记、归属核验、定向回收、reclaiming/quarantined 状态及维护请求转换；故障注入资源创建后崩溃和清理失败，验证恢复不会误清其他归属。
- [x] 4.5 实现启动单实例检查、新 bootId、全部旧租约终止和恢复前核验；重启真实服务及恢复含 active 租约的临时备份，验证旧凭证无效且未回收设备不可分配。
- [x] 4.6 将调用凭证撤销、管理员终止租约接入同一撤销与回收路径；实际撤销活跃任务，确认已有授权立即失效而不是只禁止新登录。
- [ ] 4.7 更新租约 API、回收状态和应用保留说明；在手机保留已登录应用及后台程序的情况下释放任务，验证只清平台资源、健康后回池且不声称后台副作用已消除。

- [x] 5.1 实现 WSS 任务通道、设备侧 ADB 握手及任务公钥 AUTH，能力只声明实现交集；用官方原生 adb 建连而非自制 mock 客户端，验证错任务凭证/密钥被拒绝。
- [x] 5.2 实现 OPEN 到指定设备服务的映射、子流 ID/流控和有界二进制桥接；实际运行交互 shell、shell_v2 退出状态及 exec-out PNG，确认二进制内容和 stderr/exit 语义保持。
- [x] 5.3 实现 sync 文件传输和支持服务矩阵，明确拒绝未声明服务；用原生 push/pull 往返文件并核对内容，验证不能通过任意 tcp/localabstract/reverse 访问旁路。
- [x] 5.4 将已有 transport、shell、文件和阻塞写接入租约撤销；实际保持长 shell/文件流直到释放或到期，观察后续字节被阻断，保留旧连接与重连失效回归。
- [x] 5.5 验证旧任务凭证、密钥和连接记录不能直接认证新任务网关；明确可信调用机内原生 ADB Server 端口复用不提供本地客户端任务隔离。运行同 caller 多任务、错误 stream ID、慢接收端和畸形包场景，确认不影响其他设备续租。
